Compilation

Controls
| Key | Action |
|---|---|
| ↑ Up | Move forward in the direction the camera faces |
| ↓ Down | Move backward |
| ← Left | Rotate camera counter-clockwise (turn left) |
| → Right | Rotate camera clockwise (turn right) |
| Esc | Quit |
